# 逆向思考：如果我知道死在哪，我就不去

> 大多数人研究怎么成功。芒格研究怎么失败——然后全部避开。

---

## 📜 出处

"逆向思考"作为思维方式，最早可以追溯到德国数学家**卡尔·雅可比（Carl Jacobi）**：

> 「反过来想，总是反过来想。」（Invert, always invert.）

雅可比用这个方法解决最难的数学问题——正面攻不动的，就从反面推导。但把这个思维从数学移植到商业和投资决策中，并做到极致的，是**查理·芒格**。

芒格在多次演讲中反复讲同一句话：

> 「我只想知道将来我会死在什么地方，这样我就不去那儿了。」

这不是俏皮话。这是他做了一辈子投资、活了99岁之后，最想传给世人的东西。他1986年在哈佛-西湖学校毕业典礼上的演讲，通篇不讲"如何成功"，只讲"如何确保过上痛苦的人生"——**把失败的原因全部列出来，然后一条一条避开。**

---

## 🧠 内涵

### 为什么正向思考不够？

人有天然的乐观偏误（optimism bias）。做计划时我们想的是"怎么才能成"，然后找证据支持自己能成。结果呢？**所有破产的人在做决策那一刻，都觉得自己不会破产。**

正向思考的问题是：你只能看到你愿意看到的。逆向思考逼你看到你不愿意看到的。

| 正向思考问 | 逆向思考问 |
|------|------|
| 怎么才能赚钱？ | 怎么才能亏光本金？ |
| 什么样的合伙人值得信任？ | 什么样的合伙人一定会搞砸？ |
| 我应该投哪个方向？ | 哪个方向能让我的能力一文不值？ |
| 怎么说服客户成交？ | 客户为什么绝对不会买单？ |
| 怎么过上幸福的生活？ | 怎么确保自己活得痛苦不堪？ |

前者让你兴奋，后者让你清醒。**两条路走的次数一样多，你的判断才可能接近客观。**

### 芒格的具体做法：失败清单

芒格做每一个重要投资决策前，不是先算能赚多少。他先**列一张失败清单**：

- 什么情况能让这笔投资归零？
- 这家公司的负债比例多高？
- 管理层人品有没有问题？
- 这个行业是不是在衰退？
- 市场是不是已经狂热到没有人愿意听负面观点了？

只要有一条触发了，他就不投——**不管多诱人。**

这不是保守，是**效率**。你把所有能归零的情形全避开了，剩下的自然就是安全的。用他的话说：

> 「如果你一生都在回避错误，你不需要特别聪明。你只需要**持续地不变成蠢货**。」

### "逆向思考"不是"消极思考"

容易误解：逆向思考是让人什么事都往坏处想、不敢做事？

**恰恰相反。** 逆向思考的目的是帮你**更坚定地去做对的事。**

先想清楚"怎么死"→ 确认这条路不致命 → 然后全押上去。芒格在喜诗糖果上就是这么干的——3000万的要价比账面资产高了将近四倍，按格雷厄姆的标准这太贵了。但他先逆向审了一遍：喜诗有没有被替代的风险？（品牌没人能复制）有没有价格战的风险？（消费者只认这个牌子，不需要打折）失败清单全过之后——**投。**

> 逆向思考不让你不敢出手。它让你在出手之前**把地雷踩了一遍**——踩完了还站着，这一拳你就敢打到底。

### 逆向和"本分"的关系

段永平的 Stop Doing List，本质就是逆向思考在产品中的实践。

- 正向：我们要做什么才能成功？
- 段永平的逆向：**做了什么会导致我们失败？——列出来，一件不做。**

不攻击对手、不拖欠货款、不做代工、不赊账、没有有息贷款、不做空、不用杠杆——他列出的所有"不做"背后，都是同一个思考过程：**这事做下去，最终会怎样？会以什么方式死？想清楚了，立刻停。**

芒格叫它"逆向思考"，段永平叫它"Stop Doing List"，**是完全一样的底层逻辑。**

## 📋 案例验证

### 芒格：用"失败清单"避开一辈子的坑

芒格一辈子没有犯过"致命错误"——没有爆过仓、没有踩过雷、没有碰过会清零的东西。这不是因为他比别人聪明，是因为他**每次出手前都把失败路径画了一遍。**

**案例一——抗拒杠杆：**

> 「就算只有1%的概率破产，也不应该干。因为破产的后果是不可逆的。」

他见过太多聪明人借钱投资、最终在市场极端波动中灰飞烟灭。他的逆向推演很简单：**杠杆能让你的资产归零——不管前面赚了多少年。那就不碰。**

**案例二——全市场追互联网时他在做什么：**

世纪之交，互联网泡沫，所有人都在赚钱，芒格拿的是可口可乐和喜诗糖果——"过时了"。泡沫崩了，追的人都消失了，芒格毫发无损。他的失败清单上写了一条：**"投自己看不懂的东西会亏光。"** 互联网他看不懂，所以不碰。

**案例三——喜诗糖果：逆向之后的大胆出手：**

喜诗账面资产800万，开价3000万。所有按"捡烟蒂"标准看的人都说太贵了。芒格的逆向推演：
- 失败路径一：喜诗被模仿？→ 不可能，品牌不是三个月能复制的。
- 失败路径二：价格战导致利润崩溃？→ 不可能，消费者只认这个牌子送礼。
- 失败路径三：糖果行业消失了？→ 不可能，吃的东西永远有需求。

三条全过。**2500万成交，此后为伯克希尔贡献超20亿美元利润。** 这是逆向思考最精彩的应用——不是拦着你别投，是**审完之后让你投得心安理得。**

### 段永平：不做空的那条线，是逆向划出来的

段永平做空百度亏了1-2亿美元后，把"不做空"写进了 Stop Doing List。他的逆推过程在芒格的框架下看得非常清楚：

> 我做空百度 → 市场疯狂到远超预期 → 我被迫在越涨越高的位置止损 → 亏损放大到不可承受。这条路会死。所以**不做空。**

他还推了另一条路：

> 我用杠杆 → 市场出现极端波动（一定会出现）→ 被强制平仓 → 本金清零。这条路会死。所以**不用杠杆。**

不是保守。是一个数学问题：**只要有一个路径能让你的财富归零，不管概率多低——长期来看它一定会发生。** 逆向思考就是提前找到那一条路，然后封掉。

### 傅海棠：农民也本能地用了逆向思考

傅海棠在大蒜上赚了第一笔大钱，不是因为他预测了价格——是因为他逆向推演了"**如果我错了会怎样**"：

> 大蒜价格已经跌破生产成本了，农民不种了，冷库库存正在消耗。最坏情况是价格继续跌一阵，但不可能永远低于成本——**因为再跌下去就没人种了。**

这个逻辑链条最厉害的地方在于**它反过来想了**：不是"大蒜会涨到多少"，而是"大蒜还会跌到哪去？——答案是跌不了多少了，因为已经低于生产成本了。"

于是他放心进场。后来大蒜从840元/吨涨到4000，再从13000涨到29600——两次他都重仓做对。不是赌，是**推翻了所有"会死"的可能之后，剩下的那一注。**

## 🔑 对普通人的意义

### 1. 做重大决定前，先写一张"失败清单"

买一只股票、换一个行业、跟人合伙做生意——先别想"成了能赚多少"。先坐下来写：

> 什么情况会让这件事彻底失败？

- 买股票：这个公司会不会破产？负债率多少？行业在不在衰？
- 换行业：五年后这个行业还在不在？我的技能会不会被AI替代？
- 合伙：这个人的品行我确认了吗？退出机制写了吗？

**不是列两条就完了，是写到想不出新的死法为止。** 然后——把能避开的全部避开。剩下的风险就是你该承受的。

### 2. 把"不做清单"当作你最重要的清单

新年计划列的是"要做什么"。芒格和段永平告诉你：**列一张"不做什么"。**

- 不借钱炒股 —— 一刀切，不讨论"这次不一样"。
- 不替人担保 —— 不管多好的朋友。
- 不投自己看不懂的东西 —— 哪怕身边所有人都发财了。
- 不在被情绪控制的时候做决策 —— 生气、兴奋、恐惧时，只观察，不行动。

这些规则不是从书里抄来的。是芒格、段永平、傅海棠**真金白银亏出来**的。你不用再亏一遍。直接拿来用。

### 3. 对最坏情况诚实，而不是乐观

大多数人做决策时对最好情况想得很细，对最坏情况一笔带过——"应该不会那么惨。"

**逆向思考逼你把最坏情况摆在桌子正中间：**

> 如果最坏情况发生了，我能承受吗？不能 → 调仓、减量、加保护。能 → 继续走。

不是让你因为害怕而不行动。是让你**搞清楚底线再行动。** 你知道最差会跌到哪，你就不怕波动。

### 4. 这条法则不只用于投资

芒格1986年在哈佛-西湖学校的演讲，题目是《如何保证过上痛苦的人生》。他开的方子是：反复无常、只从自身经验学习、遇到挫折就放弃、不读书、不学习、以及心怀怨恨。

**他把"过上痛苦人生"的路径全部列出来了——然后你一条一条避开，幸福就是剩下的东西。**

选学校、选职业、选对象、选城市、怎么教育孩子——所有重大决策，全可以用同一个框架：**先想清楚"怎么做会毁掉这件事"，然后把能避开的全都避开。**

> **"我只想知道将来我会死在什么地方，这样我就不去那儿了。"**
>
> 芒格99年的人生证明了一件事：你不必是最聪明的那个人。你只需要**持续地避开那些能把聪明人杀死的坑。**
>
> 逆向思考就是这件事的方法论。
